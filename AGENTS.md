# AGENTS.md

Инструкции по разработке приложения «Явка».

## 1. Назначение

Приложение реализовано для того, чтобы быстро отметить, кто пришёл, кто опоздал и кто вообще не пришёл.

## 2. Кроссплатформенность

Приложение должно работать на всех ОС одинаково, вне зависимости от железа.

## 3. Дизайн

Сделать дизайн для любого староста — «пацана» или «девочку»: универсальный, без гендерных стереотипов.

Дополнение: на десктопе (Windows/Linux/macOS) экран отметки имеет свою раскладку — кнопки отметки слева, список учащихся справа. Палитра и стили остаются общими. Android и web используют мобильную раскладку.

## 4. Git

Работа с git — только через `git add` и `git commit`. `git push` делает человек.

## 5. Запуск

Запуск приложений на устройствах делает человек.

## 6. Облачное хранилище

Нужна интеграция с Google Диск или другим облачным хранилищем. Учесть, что тот, кто интегрирует, может быть лишь со-владельцем (редактором) таблицы посещаемости.

## 7. Кнопки отметки

Должны быть 4 кнопки:

- **Пришёл**
- **Непришёл**
- **Опоздал**
- **По уважительной**

## 8. Логика отметок

- **Пришёл** — обычное пометка, без времени.
- **Непришёл** — подтверждается вторым нажатием, без времени.
- **Опоздал** — человек просто не пришёл; у опоздания пишется время.
- Время в отметке есть только у «Опоздал»: оно уходит в журнал.

## 9. Тестирование

Ключевая логика отметок посещаемости должна быть покрыта автоматическими тестами.

## 10. Локальная база данных

- Записи: **Преподаватель** (ФИО), **Предмет** (название + селект
  преподавателя и селект кабинета), **Кабинет** (название).
- Селекты работают при создании и изменении пары во вкладке
  «Расписание»; у выбранного предмета преподаватель и кабинет
  подставляются из базы, но в самой паре их можно переопределить.
- Новые записи добавляются прямо из диалога пары (кнопка «+» рядом с
  селектом) и из экрана базы (вкладка «Расписание» → иконка базы).
- Вставленный документ с расписанием пополняет базу предметами,
  преподавателями и кабинетами.
- Импорт и экспорт — JSON-файл; импорт совмещает записи по именам,
  дубликаты не создаются.
