Скачать

Все сборки живут на странице последнего релиза. Ниже — что выбрать.

Android

ФайлКому
yavka-android.apk Основной способ установки. Встроенное автообновление проверяет новые версии.

Windows

ФайлКому
yavka-windows-x64-setup.exe Инсталлятор — рекомендуется. Приложение само предложит обновление.
yavka-windows-x64.zip Портативный вариант без установки: распаковать и запустить.

Linux

ФайлКому
yavka-linux-x64.AppImage Один файл без установки и без root. Рекомендуется, автообновление.
yavka-linux-x64.deb Debian, Ubuntu и родственные дистрибутивы.
yavka-linux-x64.rpm Fedora, openSUSE и другие RPM-дистрибутивы.
yavka-linux-x64-alt.rpm ALT Linux (собран в контейнере ALT, зависимости в именах пакетов ALT).
yavka-linux-x64.tar.gz Просто архив: без пакетного менеджера, запуск вручную.

iOS (iPhone, iPad)

Поставить неподписанный IPA на iPhone нельзя — для установки нужна подпись Apple (TestFlight или инструменты вроде AltStore/Sideloadly). На телефоне рекомендуем веб-версию: откройте её в Safari и добавьте на домашний экран («Поделиться» → «На экран „Домой“») — будет как приложение.

ФайлКому
yavka-ios-unsigned.ipa Для тех, кто умеет подписывать: сборка без сертификата Apple Developer.

В браузере

Ничего устанавливать не нужно: открыть веб-версию «Явки».
